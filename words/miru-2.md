---
writing: 観る
pronunciation: みる
type: verbo ichidan (grupo II)
---

## Significado

- Ver, mirar (entretenimiento: peliculas, tele, teatro)

## Conjugaciones

Raiz: **観** (み)

| Forma           | Conjugacion                |
| --------------- | -------------------------- |
| Diccionario     | 観る (みる)                 |
| Masu            | 観ます (みます)              |
| Negativa        | 観ない (みない)              |
| Te              | 観て (みて)                 |
| Pasado          | 観た (みた)                 |
| Pasado negativo | 観なかった (みなかった)       |
| Potencial       | 観られる (みられる)          |
| Volitiva        | 観よう (みよう)              |

## Uso

{映画 (えいが) を 観 (み) る。} Ver una pelicula.

{テレビ を 観 (み) ている。} Esta viendo la tele.

{舞台 (ぶたい) を 観 (み) た。} Vi una obra de teatro.
