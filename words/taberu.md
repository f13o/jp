---
writing: 食べる
pronunciation: たべる
type: verbo ichidan (grupo II)
---

## Significado

- Comer

## Conjugaciones

Raiz: **食** (た)

| Forma           | Conjugacion                |
| --------------- | -------------------------- |
| Diccionario     | 食べる (たべる)             |
| Masu            | 食べます (たべます)          |
| Negativa        | 食べない (たべない)          |
| Te              | 食べて (たべて)             |
| Pasado          | 食べた (たべた)             |
| Pasado negativo | 食べなかった (たべなかった)   |
| Potencial       | 食べられる (たべられる)      |
| Volitiva        | 食べよう (たべよう)          |

## Uso

{ご飯 (はん) を 食 (た) べる。} Comer arroz.

{おやつ を 食 (た) べました。} Comi la merienda.

{何 (なに) を 食 (た) べたい？} Que quieres comer?
