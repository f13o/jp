---
writing: 寝る
pronunciation: ねる
type: verbo ichidan (grupo II)
---

## Significado

- Dormir
- Acostarse

## Conjugaciones

Raiz: **寝** (ね)

| Forma           | Conjugacion                |
| --------------- | -------------------------- |
| Diccionario     | 寝る (ねる)                 |
| Masu            | 寝ます (ねます)              |
| Negativa        | 寝ない (ねない)              |
| Te              | 寝て (ねて)                 |
| Pasado          | 寝た (ねた)                 |
| Pasado negativo | 寝なかった (ねなかった)       |
| Potencial       | 寝られる (ねられる)          |
| Volitiva        | 寝よう (ねよう)              |

## Uso

{もう 寝 (ね) る。} Ya me voy a dormir.

{昨日 (きのう) 早 (はや) く 寝 (ね) た。} Ayer me dormi temprano.

{まだ 寝 (ね) ていない。} Todavia no me he dormido.
