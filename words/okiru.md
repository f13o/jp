---
writing: 起きる
pronunciation: おきる
type: verbo ichidan (grupo II)
---

## Significado

- Levantarse, despertarse
- Ocurrir, suceder

## Conjugaciones

Raiz: **起** (お)

| Forma           | Conjugacion                |
| --------------- | -------------------------- |
| Diccionario     | 起きる (おきる)             |
| Masu            | 起きます (おきます)          |
| Negativa        | 起きない (おきない)          |
| Te              | 起きて (おきて)             |
| Pasado          | 起きた (おきた)             |
| Pasado negativo | 起きなかった (おきなかった)   |
| Potencial       | 起きられる (おきられる)      |
| Volitiva        | 起きよう (おきよう)          |

## Uso

{毎朝 (まいあさ) 六時 (ろくじ) に 起 (お) きる。} Me levanto a las seis cada manana.

{まだ 起 (お) きていない。} Todavia no se ha levantado.

{何 (なに) が 起 (お) きた？} Que ocurrio?
