---
writing: 見る
pronunciation: みる
type: verbo ichidan (grupo II)
---

## Significado

- Ver, mirar (general)

## Conjugaciones

Raiz: **見** (み)

| Forma           | Conjugacion                |
| --------------- | -------------------------- |
| Diccionario     | 見る (みる)                 |
| Masu            | 見ます (みます)              |
| Negativa        | 見ない (みない)              |
| Te              | 見て (みて)                 |
| Pasado          | 見た (みた)                 |
| Pasado negativo | 見なかった (みなかった)       |
| Potencial       | 見られる (みられる)          |
| Volitiva        | 見よう (みよう)              |

## Uso

{猫 (ねこ) を 見 (み) た。} Vi un gato.

{あれ を 見 (み) て。} Mira eso.

{新聞 (しんぶん) を 見 (み) る。} Leer el periodico.
