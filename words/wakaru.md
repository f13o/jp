---
writing: 分かる
pronunciation: わかる
type: verbo godan (grupo I)
---

## Significado

- Entender, comprender
- Saber (tener conocimiento de algo)

## Conjugaciones

Raiz: **分** (わ)

| Forma           | Conjugacion                  |
| --------------- | ---------------------------- |
| Diccionario     | 分かる (わかる)               |
| Masu            | 分かります (わかります)        |
| Negativa        | 分からない (わからない)        |
| Te              | 分かって (わかって)            |
| Pasado          | 分かった (わかった)            |
| Pasado negativo | 分からなかった (わからなかった)  |
| Potencial       | 分かれる (わかれる)            |
| Volitiva        | 分かろう (わかろう)            |

## Uso

{日本語 (にほんご) が 分 (わ) かる。} Entiendo japones.

{分 (わ) かりました。} Entendido.

{この 言葉 (ことば) が 分 (わ) からない。} No entiendo esta palabra.
